# RSS-ассистент в Telegram

Поток читает RSS-источники, фильтрует и обрабатывает публикации, затем отправляет результаты через Telegram. В экспорте 132 узла; перед запуском проверьте подключённые модели и credentials.

## Импорт и настройка

Импортируйте `workflow.json` в n8n, создайте credentials для используемых сервисов и замените значения `<CONFIGURE_IN_N8N>` и адреса `YOUR_*` на свои. Экспорт специально очищен от учётных данных и рабочих идентификаторов; сразу после импорта поток не запускайте, сначала проверьте узлы и связи.
