# RSS-ассистент в Telegram

Схема на 132 узла: собирает публикации из RSS, обрабатывает их и взаимодействует с пользователем через Telegram.

В JSON оставлены узлы и связи для просмотра графа. Конфигурация и параметры узлов удалены; это не готовый к запуску экспорт. Исходный файл сохранён локально без изменений.
