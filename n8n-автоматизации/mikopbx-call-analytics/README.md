# AI-анализ звонков MikoPBX

Схема основного потока: получение записей звонков, транскрибация, AI-классификация и краткое содержание, подготовка документов и отправка результата в CRM.

Конфигурация удалена, а имена и внутренние номера обезличены. JSON предназначен для просмотра структуры; все узлы надо настроить заново. Исходник не менялся.
