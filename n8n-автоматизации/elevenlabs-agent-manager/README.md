# Telegram-бот для управления агентами ElevenLabs

Схема бота для списка голосовых агентов, изменения prompt и приветствия, добавления текста и URL в базу знаний. Включает сессию MySQL и AI-разбор команд.

Опубликована только схема узлов и связей; credentials и настройки узлов удалены. Исходный JSON сохранён локально без изменений.
