# Telegram-бот для управления агентами ElevenLabs

Бот показывает список голосовых агентов и позволяет менять prompt и приветствие, добавлять текстовые документы и URL в базу знаний. Состояния диалога хранит MySQL; текстовые команды обрабатывает AI-узел. Credentials удалены.

## Импорт и настройка

Импортируйте `workflow.json` в n8n, создайте credentials для используемых сервисов и замените значения `<CONFIGURE_IN_N8N>` и адреса `YOUR_*` на свои. Экспорт специально очищен от учётных данных и рабочих идентификаторов; сразу после импорта поток не запускайте, сначала проверьте узлы и связи.
