# Парсер и мониторинг доменов

Workflow на 58 узлов для проверки доменов и сбора результатов в автоматизированном процессе. В экспорте оставлены типы и расположение узлов, связи между ними, но удалены настройки узлов и конфигурационные значения.

## Импорт

Импортируйте JSON как схему для просмотра. Узлы требуют повторной настройки: добавьте свои источники данных, credentials, параметры запросов и хранилище. Это очищенная демонстрационная схема, не готовая к запуску.
